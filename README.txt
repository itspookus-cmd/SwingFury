SwingFury 0.1.0

This is the initial SKSE plugin scaffold for Skyrim Special Edition runtime 1.6.1170.

Current milestone:
- Loads through SKSE.
- Writes a "SwingFury loaded" message to the SKSE log.
- Ships a configuration file for future settings.

Important: attack-speed modification is NOT implemented in this build yet.
Do not expect faster attacks from this version.

Install:
1. Download the SwingFury-mod artifact from the successful GitHub Actions run.
2. In Mod Organizer 2, use Install a new mod from archive.
3. Select the downloaded ZIP.
4. Enable SwingFury and launch Skyrim through SKSE.

Requirements:
- Skyrim Special Edition runtime 1.6.1170.
- SKSE64 2.2.6 for runtime 1.6.1170.
- Address Library for SKSE Plugins, All-in-One (AE).

Log:
Documents\My Games\Skyrim Special Edition\SKSE\SwingFury.log
