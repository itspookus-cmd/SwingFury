SwingFury - faster melee swings, default recovery.

Install: copy the SKSE folder from the build into Skyrim\Data (or install the
zip with your mod manager). Requires SKSE64 2.2.6 and Address Library for SKSE Plugins.
Launch the game with skse64_loader.exe.

Tuning: edit Data\SKSE\Plugins\SwingFury.ini
Log:    Documents\My Games\Skyrim Special Edition\SKSE\SwingFury.log
